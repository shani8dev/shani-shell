- security_keys (L, security): port both PAM config groups into `bridge/u2f.py` — FIDO2 value writes (`authfile`/`origin`/`appid`, guarded flags) and Yubico OTP mode/id/chalresp — with read-back and typed confirmation.
- services (M, feature): add a system-unit scope to `bridge/services.py` with enabled/disabled state, `enable/disable --now` and a per-unit `journalctl` log read.
- setup (M, feature): add `/etc/skel` coverage and wizard-state reads plus a guarded re-provision button to a `bridge/system_setup.py` page.
- sharing (L, security): author `/etc/exports.d/shani-cassini.exports` through one helper with canonical options, exclusive-option checks and warnings for `no_root_squash`/`all_squash`.
- smart (M, data-safety): read smartd config and service state into the SMART bridge so on-demand attribute reads are not mistaken for scheduled testing.
- smartcard (L, security): add subject→account add/edit/remove through the system's pkexec rule with `pcsc_scan` reader states in `bridge/system_access.py`.
- smb (L, security): port `testparm`/`pdbedit`/socket reads and guest-denied share authoring from `smb.py` into a GTK-free `bridge/system_smb.py`.
- ssh_keys (M, security): add file/dir mode checks and StrictModes risk text to `bridge/sshkeys.py list`, and show them in `SettingsAccount.qml`.
- storage (M, data-safety): add a `storage-info` verb to `bridge/system_health.py` and render its capacity, maintenance and subvolume rows in `SettingsStorage.qml`.
- system (S, feature): add `reboot_needed` to `bridge/bootinfo.py` FIELDS and swap/zram rows to the machine facts read.
